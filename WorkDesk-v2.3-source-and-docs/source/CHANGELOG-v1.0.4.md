# WorkDesk Chrome v1.0.4

* Websites (pinned URLs / bookmarks) now default to **real Chrome tabs in the WorkDesk Chrome window**, next to the WorkDesk tab in Chrome's tab strip. WhatsApp, Meet and Google sign-in work as in a normal Chrome (the in-page frame of v1.0.3 is blocked by the sites' own cookie / sign-in checks).
* Default window mode is now *Normal window* (Chrome's tab strip visible); Kiosk is a setting. In a normal window the duplicate minimise / maximise / close buttons of the header are hidden.
* The in-page ("inside the WorkDesk window") display stays available: Settings → Website tabs, or per bookmark (Open in).
* Fixed: the red "WorkDesk could not start or attach to its Chrome window … Chrome has not finished starting yet" message that appeared while Chrome was still connecting. It is now shown only if startup really fails.
* The hover bar on website tabs is only used in kiosk mode.
* Coming back to the WorkDesk tab leaves the "website" placeholder view.
