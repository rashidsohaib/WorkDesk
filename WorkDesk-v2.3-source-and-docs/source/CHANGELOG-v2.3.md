# WorkDesk Chrome v2.3

Fixes and additions
* **Font colour and highlight colour menus now work** in the Compose editor and the Signature editor. The colour palette was being clipped by the scrolling toolbar; it now opens on top of the page and applies the colour. Esc or a click elsewhere closes it.
* **More bookmark icons**, including social-style ones (share, like, heart, chat, video, camera, music, hash, @, news, megaphone, people and more), plus a **Site icon** choice that uses the website's own icon. WorkDesk fetches it only from the bookmarked site, stores it locally, and refreshes it when you open the site. Brand logos are not drawn.
* **Faster PDF attachments.** The message is kept in memory after it is opened, so opening an attachment no longer reconnects to Gmail, and PDF pages are drawn only as they come into view.
* **PDF Preview: print and marking.** Print (with your marks), draw, highlight, add text, and place a **scanned signature** (upload once, background removed, reuse any time; move or resize it afterwards). Undo/redo/delete are included. "Save a copy with your marks" writes `<name> (marked).pdf` to Downloads; the original is never changed.
* **Name bubbles on the left rail.** Hover over any icon to see its name.
* Printing a mail thread now uses the same print dialog.
